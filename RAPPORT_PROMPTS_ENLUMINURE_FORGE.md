# Prompt Codex/ChatGPT — Pilote Forge en style enluminure médiévale

## Contexte

Tu produis des assets visuels pour **L’Arbre des Savoirs**, application éducative interactive pour enfants de 4-8 ans.

Le moteur de jeu existe déjà. Les assets actuels sont des SVG de prototype. Ils doivent être remplacés par des images de qualité, cohérentes avec une référence canonique : une scène de forgeron médiéval en style manuscrit enluminé, avec fond outremer, bordure or/vermillon/malachite, cernes noirs expressifs, forge en pierre, feu vermillon-or, enclume, établi, outils et détails de marge.

Le style n’est pas du flat design. Il doit évoquer une **enluminure médiévale réinterprétée pour un jeu enfant** : riche, lisible, chaleureux, ornemental, non photoréaliste.

## Palette canonique

Utilise uniquement cette palette, avec variations très légères par transparence ou texture :

- Vermillon : `#C0392B`
- Outremer : `#1A3A8F`
- Or chaud : `#D4A017`
- Malachite : `#2D7A4F`
- Terre d’ombre : `#6B3A2A`
- Ivoire parchemin : `#F5EDD6`
- Noir d’encre : `#1A1A1A`
- Gris acier : `#5A6472`

Interdits : blanc pur `#FFFFFF`, noir pur `#000000`, couleurs néon, rendu plastique, photoréalisme.

## Règles communes

Pour tous les assets :

- style manuscrit médiéval enluminé ;
- contours nets et expressifs en noir d’encre `#1A1A1A` ;
- formes légèrement irrégulières, peintes à la main ;
- volume par assombrissement de la couleur, pas par lumière réaliste froide ;
- rehauts or `#D4A017` sur métal, arêtes, détails importants ;
- silhouette lisible par un enfant de 4 ans ;
- pas de texte, pas de watermark, pas de signature ;
- objet centré, occupant environ 75-85 % du cadre ;
- ombre portée douce intégrée en Terre d’ombre semi-transparente ;
- fond transparent pour les props, icônes et résultats ;
- fond plein uniquement pour les scènes.
